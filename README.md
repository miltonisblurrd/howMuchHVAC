# How Much? Website

Next.js + MDX marketing site and demo client portal for **How Much? Air & Home Improvements**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo portal

- URL: `/portal/login`
- `demo@trusthowmuch.com` / `howmuch`
- `maria@example.com` / `howmuch`

## Content

- Blog MDX: `src/content/blog`
- FAQ MDX: `src/content/faqs`
- Brand kit (source PDFs): `../brand-kit`

## Key routes

| Route | Purpose |
|-------|---------|
| `/` | Home |
| `/ads` | Paid traffic landing |
| `/booking` | Quote / booking wizard |
| `/services` | HVAC services |
| `/service-areas` | City SEO pages |
| `/projects` | Case studies |
| `/reviews` | Reviews + Google deep-link flow |
| `/brand` | Brand guidelines & social examples |
| `/portal` | Demo client portal |
